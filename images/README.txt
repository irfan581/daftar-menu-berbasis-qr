FOLDER FOTO MENU
================

Taruh foto menu asli di folder ini.

Nama file harus SAMA PERSIS dengan yang tertulis di file "menu-data.js"
pada field "gambar". Contoh:

    gambar: "images/pentol-urat.jpg"   ->  taruh file: images/pentol-urat.jpg

Selama foto belum ada, kartu menu otomatis menampilkan ikon placeholder
(🍢 untuk Pentol, 🍽️ untuk Tambahan) — jadi tampilan tetap rapi.

Tips foto:
- Bentuk persegi (1:1) paling bagus, mis. 600x600 px.
- Format .jpg atau .webp agar ukuran kecil & cepat dimuat.
